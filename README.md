🌩️ Emergency Weather Alert Dashboard

A modern single-page weather dashboard built with Vite, Tailwind CSS, and Vanilla JavaScript.
The app detects the user's location, fetches real-time weather data, and redirects to a live radar map.

🚀 Features

📍 High-accuracy geolocation detection

🌡️ Real-time temperature using Open-Meteo API

🌪️ Auto redirect to Windy.com live radar

🌙 Dark mode glassmorphism UI

📱 Fully responsive mobile layout

⚠️ Graceful error handling for denied location access

🛠️ Tech Stack

Vite

Tailwind CSS

Vanilla JavaScript

Open-Meteo API

Windy Radar Map
